## Інструкція із запуску проєкту

Для локального запуску застосунку на комп'ютері мають бути встановлені актуальны версії **Node.js** та пакетний менеджер **npm**.

```bash
#Клонування
git clone https://github.com/utland/fe-labs/tree/main/lab7
cd lab7

#Встановлення залежностей
npm install

#Запуск
npm run dev
```
